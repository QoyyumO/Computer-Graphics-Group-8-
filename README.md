# 3D Scene Composition Project

This project showcases a 3D scene composition using SDL and OpenGL. The project consists of two main components: an SDL implementation and an OpenGL implementation of a rotating octagonal prism.

## Scene Description

### OpenGL Scene: "Octagonal Prism in Motion"

The OpenGL scene features a rotating octagonal prism. This geometric shape, with its continuous rotation, symbolizes the constant evolution and multifaceted nature of learning. The simplicity of the shape creates a visual metaphor for the balance between fundamental concepts and their complex applications in education.

## Final Composition

The final composition integrates the OpenGL-rendered octagonal prism into a visually striking image. The composition features a luxurious black and gold theme with intricate floral designs, providing an elegant frame for the scene.

## Getting Started

To run the project, please follow these steps:

1. Clone the respective repositories (SDL or OpenGL) using the provided GitHub links.
2. Follow the setup instructions in each repository's README file.
3. Compile and run the programs as per the instructions.

## Dependencies

- SDL2 (for the SDL implementation)
- OpenGL libraries (for the OpenGL implementation)

Please ensure you have the necessary dependencies installed before running the project.
